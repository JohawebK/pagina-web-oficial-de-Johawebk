¡Bienvenido al repositorio oficial de la Landing Page de **JohawebK**! Este proyecto es una vitrina tecnológica interactiva diseñada con una estética *cyberpunk* futurista, que expone las capacidades del meta framework del futuro: la velocidad extrema de **Astro**, la ergonomía declarativa de **React** y un núcleo blindado por defecto mediante componentes de ciberseguridad defensiva.

La interfaz cuenta con simuladores dinámicos en tiempo real que reflejan el flujo de trabajo de un desarrollador y las auditorías automatizadas del *Blue Team*.

---

## ⚡ Características de la Página Web

La landing page está construida como una aplicación de una sola página (SPA) altamente optimizada, modular e interactiva que incluye:

*   **Bento Grid de Arquitectura:** Desglose visual de los pilares del framework (Ecosistema JSX, Rendimiento Isla y SAST integrado).
*   **Línea de Tiempo Interactiva:** Un flujo asimétrico paso a paso conectado a una **Terminal Virtual** a la derecha. Al hacer clic en los pasos (01, 02, 03), la terminal actualiza dinámicamente su salida simulando la creación, codificación y el despliegue del proyecto.
*   **Pestañas de Documentación con Menú Lateral:** Un *sidebar* dinámico que permite navegar por los conceptos de *Enrutamiento*, *Islas Dinámicas* y *Reglas Blue Team* de forma fluida y sin recargar la página.
*   **Consola Live del Blue Team:** Un simulador interactivo de centro de operaciones de seguridad (SOC) con filtros por severidad de alertas (`TODAS`, `ALTA`, `MEDIA`, `BAJA`) para inspeccionar vulnerabilidades simuladas (XSS, CORS, etc.).
*   **Utilidades de Productividad:** Botones inteligentes de copiado al portapapeles con retroalimentación visual en los comandos del CLI.

---

## 🛠️ Tecnologías Utilizadas

*   **HTML5:** Estructura semántica avanzada.
*   **Tailwind CSS:** Framework utilitario para todo el estilizado, paleta de colores personalizada (`space-dark`, `cyber-blue`, `cyber-orange`) y efectos de resplandor (*glow*) de neón.
*   **Vanilla JavaScript (ES6+):** Lógica nativa ultraligera para la manipulación del DOM, reactividad de las pestañas, filtrado de la consola y control de la terminal interactiva.
*   **Google Fonts:** Tipografía de alta fidelidad para entornos de desarrollo (*JetBrains Mono*).
