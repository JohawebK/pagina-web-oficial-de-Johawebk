Enrutamiento Basado en Archivos

JohawebK automatiza el mapeo de tus puntos de entrada mediante el sistema de archivos de tu directorio. Cada archivo renderizado en src/pages/ se convierte en un endpoint HTML estático optimizado.

// Estructura del Árbol de Páginas
📦 src/pages/
├── 📄 index.jhk -----------> tu-dominio.com/
├── 📄 sobre-nosotros.jhk ----> tu-dominio.com/sobre-nosotros
└── 📁 api/
    └── 📄 check-vulnerability.js

Hidratación Parcial de Componentes

Por defecto, JohawebK no envía código JavaScript al lado del cliente, garantizando una carga inmediata. Para aquellas zonas interactivas que exijan reactividad (ej. menús desplegables o formularios con hooks de React), se utiliza la directiva explícita de aislamiento.

// El botón será interactivo en el navegador, el resto permanece estático
<BotonContador client:load />

Configuración de Políticas Blue Team

Protege tu código en tiempo de compilación. A través de las políticas de seguridad integradas en el núcleo del framework, puedes definir reglas estrictas de análisis estático (SAST) y detener compilaciones si se infringen parámetros de seguridad.

johawebk.config.json
{
  "security": {
    "auditOnBuild": true,
    "failOnSeverity": "ALTA"
  }
}
